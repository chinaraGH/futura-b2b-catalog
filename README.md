# futura-b2b-catalog

B2B architectural panels website. Features: interactive catalog filtering, comparison table, cost calculator, PDF download, and NocoDB lead API.
B2B-платформа. Реализованы: интерактивный каталог материалов с фильтрами, таблица сравнения с конкурентами, калькулятор расчета сметы, кнопка скачивания PDF-каталога и отправка квалифицированных лидов напрямую в базу NocoDB.
