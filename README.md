# futura-b2b-catalog

B2B architectural panels website. Features: interactive catalog filtering, comparison table, cost calculator, PDF download, and Supabase lead API.
B2B-платформа. Реализованы: интерактивный каталог материалов с фильтрами, таблица сравнения с конкурентами, калькулятор расчёта сметы, кнопка скачивания PDF-каталога и сохранение лидов напрямую в Supabase (таблица `leads`).
